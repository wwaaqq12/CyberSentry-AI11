# 🛡️ CyberSentry AI

**A Local File Security Analysis and Integrity Checking Tool**

CyberSentry AI is a Python-based cybersecurity project designed to analyze local files and help users understand potential file characteristics through entropy analysis and integrity reporting.

## ✨ Features

- 🔍 **File Analysis:** Analyze selected files locally.
- 📊 **Entropy Analysis:** Calculate file entropy to identify unusual patterns.
- 🔐 **Integrity Reporting:** Generate reports to support file integrity checks.
- 📄 **JSON Reports:** Export analysis results in JSON format.
- 🖥️ **Desktop Interface:** Use a graphical interface built with Python.
- 🔒 **Local Analysis:** Designed to analyze files on the local machine.

## 🚀 Getting Started

### Requirements

- Python 3
- Git (optional, for cloning the repository)

### Installation

Clone the repository:

```bash
git clone https://github.com/wwaaqq12/CyberSentry-AI11.git
```

Open the project directory:

```bash
cd CyberSentry-AI11
```

### Run the Application

If the desktop interface is the intended entry point, run:

```bash
python desktop_app.py
```

## ⚠️ Important Security Note

Entropy analysis alone cannot determine whether a file is malicious. Results should be treated as informational indicators, not as a replacement for antivirus software or professional malware analysis.

Only analyze files you are authorized to inspect.
